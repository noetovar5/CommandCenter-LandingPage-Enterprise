Noe Tovar Enterprise Command Center
LCARS-inspired static website dashboard

UPLOAD INSTRUCTIONS
1. Unzip this package.
2. Upload index.html, styles.css, and script.js to your web server's public folder.
   Common folders include public_html, wwwroot, htdocs, or /var/www/html.
3. Open your domain or server IP in a browser.

CUSTOMIZATION
- Edit index.html to change links, names, titles, or dashboard sections.
- Edit styles.css to adjust colors, layout, spacing, and LCARS styling.
- Edit script.js for clock, notes, or future interactive features.

NOTES
- This is a static website, so it does not require PHP, Node.js, .NET, SQL Server, or a database.
- The Captain's Notes box uses browser local storage, meaning notes are saved only on the browser/device where they are typed.
- The embedded YouTube animation requires internet access.

Suggested homepage use:
Set this site as your browser start page and use it as your daily command center.
